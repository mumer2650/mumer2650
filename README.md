### ✈️ AERO — Real-Time Flight Tracking System

A geographically sharded PostgreSQL cluster (Lahore, Dubai, London hubs) for zero-fault seat booking, with Neo4j graph algorithms computing multi-hop layover routes in milliseconds, a Redis-backed distributed seat-lock to prevent double-booking, and real-time aircraft coordinates streamed to React via WebSockets.
